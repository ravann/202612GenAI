# RB-02 Account lockout and password reset

For staff accounts managed by the identity provider `idp-01` and the directory server `dir-01`.

## How lockout works

- An account is locked after 5 failed sign-in attempts in 10 minutes.
- A locked account unlocks itself after 15 minutes.
- Service desk staff never ask for or type a user's password.

## Self-service reset (preferred)

1. Send the user to the self-service password page.
2. The user confirms their identity with their registered MFA device.
3. The user chooses a new password of at least 14 characters.
4. The new password works everywhere within 5 minutes.

## Assisted reset

Use this only when the user has lost their MFA device.

1. Verify the user's identity with their line manager by phone.
2. Issue a one-time reset link from the directory admin console. The link expires after 30 minutes.
3. Ask the user to register a new MFA device straight after the reset.
4. Record the manager's name and the time in the incident.

## When to escalate

- More than 10 lockouts from one office in an hour can mean a password-spraying attempt. Raise a P2 incident and inform the security team.
