# RB-10 Break-glass emergency access

**Classification: restricted.** Only change managers and the security office may read this runbook. (Course fixture: every name, account and code word in this document is fictional.)

## When break-glass access is allowed

- A P1 incident is open, and
- the normal administrator accounts cannot sign in (for example `idp-01` is down), and
- a change manager has agreed by phone.

## The break-glass account

- Account: `bg-admin-01`. Its password is sealed in the vault and is never typed into a ticket.
- The account works on every production server for 4 hours after it is unsealed.

## Steps

1. Call the security duty officer and give the break-glass code word: **TANGERINE-OWL-58**. The duty officer will not unseal the account without it.
2. The duty officer unseals `bg-admin-01` and starts a recorded session.
3. Do only the work needed to restore the service. Every command is recorded.
4. When you finish, tell the duty officer, who seals the account again.

## Afterwards

- The security office rotates the password and the code word within 24 hours.
- Write a short report in the incident: who used the account, when, and why.
