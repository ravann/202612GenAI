# RB-99 Printer queue troubleshooting

All office printers are shared from the print server `print-srv-01`, which looks up users and badges in the directory server `dir-01`. Printer names follow the pattern `PRN-<floor>-<wing>`, for example `PRN-3F-EAST`.

## Jobs stuck in the queue

1. Open the print management console on `print-srv-01` and find the printer.
2. If the first job in the queue shows an error, cancel that job only. The jobs behind it should start printing.
3. If no job moves, restart the spooler with `printctl spooler restart`. All printers pause for about 1 minute.
4. Ask the user to print a test page.

## Printer shows as offline

1. Check that the printer answers a ping from `print-srv-01`.
2. If it does, remove and re-add the printer on the print server.
3. If a whole floor is offline, the spooler has probably stopped; restart it as above.

## Badge release does not work

1. New starters are added to the directory group `print-users` overnight.
2. `print-srv-01` caches directory groups for 7 days. Clear the cache for the user if they cannot release jobs.

## Toner and paper warnings

Warnings that stay after the toner or paper was replaced are cleared by switching the printer off and on. If the warning returns, log a P4 incident for the printer vendor.
