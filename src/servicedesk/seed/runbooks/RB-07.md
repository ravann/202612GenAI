# RB-07 Payroll portal HTTP 500 errors

The payroll portal runs on `web-payroll-01` and `app-payroll-01`, with the payroll database `db-09`. Sign-in goes through the identity provider `idp-01`.

## Error PAY-500-SESSION

The portal could not save the user's session.

1. Check the size of the session table on `db-09`. Above 2 million rows, inserts start to fail.
2. Purge sessions older than 24 hours with the scheduled job `payroll-session-purge`, run by hand.
3. Ask an affected user to sign in again.

## Error PAY-500-DB

The application cannot reach `db-09`.

1. Check that `db-09` is up and that its connection pool on `app-payroll-01` is not exhausted (limit 200 connections).
2. At month end the pool can fill up. Raise the limit to 300 for the peak only, and record this in the incident.

## Error PAY-500-PDF

Payslip or tax form PDFs fail to generate.

1. Check free space in the temporary folder on `app-payroll-01`.
2. Restart the PDF worker service.

## Escalation

Payroll errors in the last three working days of the month are P2 at least (see RB-09). Inform the HR systems team.
